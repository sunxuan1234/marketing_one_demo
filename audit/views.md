# V3 `views.js` 精校与证据审计

## 1. 范围与结论

本轮仅修改：

- `workbench-v3/assets/views.js`
- `workbench-v3/audit/views.md`

未修改 V1、V2，也未改动 V3 的 `data.js / engine.js / app.js / catalog.js`。保留 `WBViews.card/cards/table/featureFooter/commonMetricChart` 公共接口；`featureFooter()` 现在返回空字符串，避免重复通用明细表。

已完成六个业务视图重构：应收、DMA、预测、源工单、数据治理、报表与只读设置。整体结论：

- 应收卡片、图表、明细和 CSV 统一读取当前筛选后的 `D.bills`；调整、退款、特殊开账和待处理账只读取 `D.adjustments`，当前为空即空态。
- DMA 不再由行政区、经营单位或售水量构造拓扑、夜流、压力和覆盖率；`D.dmaNodes=[]`、`D.dmaReadings=[]` 时保留简洁缺数态。
- 预测保留售水量/收费率/产销差率/售水单价四个原型入口，后三项标为候选；售水量保留历史与月/季/年粒度，未来预测无数据即待接入。未使用计划值系数、固定 MAPE、权重滑块或假发布。
- 工单默认源只读，移除平台整改协同、自动转单、考核数字、虚构 SLA 和五级打开轨迹；仅展示已有收发处理字段。
- 治理按实际样例批次和基础信息异常展示；`records=null` 保持未知，不按 0 汇总，不模拟复检。
- 报表按当前目录动态生成 20 张，全部具有各自字段定义与数据状态；20 张均可打开预览或字段状态，空结果不能导出 CSV。
- 设置仅保留计划样例、字典、组织账号、字段关联、报表参数和日志状态，不含通用草案编辑器或发布权限。

## 3. 分模块处置

| 模块 | 保留/实现 | 删除或空态 | 数据与导出 |
|---|---|---|---|
| 应收 | 应收/实收/欠费/收费率卡；按性质、单位、组织图；账务年欠费；账单、欠费用户、5000m³专项、调整、退款、特殊账页签 | 5000m³不筛选全部账单；部分缴费欠费水量待核；无调整/退款记录即空态；无虚构轨迹 | 全部来自同一组筛选账单；当前表导出剔除“操作”列 |
| DMA | 物理拓扑、夜流、24小时、压力、供售水五个业务页签 | 当前无拓扑和采集，全部精确缺数态；不出假图、假 KPI | 有真实集合时才按已有字段生成表格；当前为空 |
| 预测 | 四指标入口；实际历史；售水量月/季/年粒度；下月/季度/年度预测页签 | 三个非售水指标为候选；无未来预测、模型版本或 MAPE；无保存发布 | 历史导出区分实际和计划；切回历史时恢复历史 `WB.currentTable` |
| 工单 | 类型与状态统计；源工单字段明细与只读详情 | 无 B 协同、自动转单、考核、SLA 推算、五级轨迹 | `sentAt/receivedAt/processedAt` 原样展示；`limitAt/events` 空即未知 |
| 治理 | 批次与记录数卡、系统样例快照、批次表、基础信息异常表 | 无在线生产状态、无延迟推算、无模拟复检 | `records=null` 不强转 0；只汇总已提供记录 |
| 报表 | 动态 20 张目录、类别统计、逐 ID 专属字段、预览/字段状态和真实 CSV | 删除抄见率；无生成次数、耗时、成功率；无通用经营七列 | 当前 18 种列签名；周检/故障各自合理共用结构；所有行通过列数校验 |
| 设置 | 计划样例、字典、组织账号、源键映射、N 参数、日志状态 | 无通用配置草案、无假发布、无 `ext_fee_items` 技术扩展冒充当前业务设置 | MNF 01:00—04:00 标为待确认且未用于计算 |

补充约束：

- `work/data` 的源工单和批次不受上一页遗留月份限制；对应图设置 `periodFilter:false`，读取时使用维度过滤而非隐藏月份过滤。
- 应收卡片“欠费金额”指未结清账单金额；5000m³专项独立采用近 5 年窗口。
- `V.cards` 的注册用户单位为期末“户”，不再使用“户·月”。

## 6. Lead最终集成修正

- 小区、册本按经营单位+组织+本地名称组合归组；历史存量按立户/注销日期判断，不把当前“正常”状态冒充过去状态。
- 换表与异常状态报表受实际事件账期过滤；前后均满足N期才计算均值变化。

- 预测指标切换不再由隐藏未来面板覆盖历史导出对象；返回历史时重建可见图，避免隐藏容器初始化为0宽。未来售水页保留5类有据输入的待接入状态，不添加权重。
