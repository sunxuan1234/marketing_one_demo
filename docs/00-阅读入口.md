# 营销一体化开发交付包

版本：V4.2 / 2026-11-08。原型入口：项目根目录 `index.html`，可离线打开。

## 给 GPT 的阅读顺序

1. `01-成果分析与决策.md`：哪些来自用户，哪些来自 Gemini，哪些是本次修正。
2. `02-完整开发规格.md`：需求、口径、架构、接口、权限、实施及验收。
3. `03-数据库字典.md` 与 `sql/001-baseline.sql`：字段定义与新库基线。
4. `04-原型映射与报表.md`：当前原型路由、源码、21 张报表的逐项清单。
5. `05-GPT开发指令.md`：直接复制给 GPT 的开发约束及分阶段任务。
6. `06-验证记录.md`：本次已验证与未验证的内容，不能沿用历史截图作为本次验证。

本包描述正式系统的开发目标，不表示已经实现后端。SQL 是供评审的新库基线，未连接、修改任何现有数据库。用户已确认仅测试库、允许新建库，并确认双轨主键与16位Luhn编码；源字段与正式指标口径仍需签认。对应未决事项见文档 01。

原型继续使用本地 JavaScript + ECharts；正式产品按用户指定的 Vue 3 + JDK 25 + Spring Boot 3.5 + PostgreSQL / TimescaleDB HA 实现。不要把原型模拟数据生成器搬入正式服务。
